If you use VMs for experiments, consider Vagrant or similar tools for fast
fresh VM provisioning.

Reference: https://wiki.debian.org/Vagrant

```shell
sudo apt update
sudo apt install vagrant-libvirt libvirt-daemon-system
sudo usermod --append --groups libvirt $USER
```

Log out and back in to let group membership take effect (`id -nG | grep libvirt`)

```shell
mkdir bookworm-vm
cd bookworm-vm

cat > Vagrantfile << EOF
NAME = "xen-x86-bookworm-host"

Vagrant.configure("2") do |config|

  config.vm.box = "debian/bookworm64"
  config.vm.define NAME
  config.vm.hostname = NAME

  config.ssh.forward_agent = true

  config.vm.network :forwarded_port, guest: 22, host: 12345

  config.vm.provider "libvirt" do |v|
    v.default_prefix = ""
    v.memory = 40960
    v.cpus = 24
  end

  config.vm.provision :shell, inline:
    "timedatectl set-timezone America/Chicago"
end
EOF

vagrant up
```

Log in to the VM

```shell
vagrant ssh
```

Or populate your `~/.ssh/config` with the content generated by the following
command:

```shell
vagrant ssh-config |& tee -a ~/.ssh/config
# Host xen-x86-bookworm-host
#   HostName 192.168.121.149
#   User vagrant
#   Port 22
#   UserKnownHostsFile /dev/null
#   StrictHostKeyChecking no
#   PasswordAuthentication no
#   IdentityFile /users/wtj/bookworm-vm/.vagrant/machines/xen-x86-bookworm-host/libvirt/private_key
#   IdentitiesOnly yes
#   LogLevel FATAL
#   ForwardAgent yes
```

Then you can `ssh xen-x86-bookworm-host` depending on your output.

See the VM status

```shell
vagrant status
# Most other vagrant commands need to be run under the directory of
# Vagrantfile. In case you forget where that is, the below can be run
# everywhere
vagrant global-status
```

When you are done with the VM, clean up

```shell
vagrant halt    # Stop the instance
vagrant destroy # Delete the instance
```
